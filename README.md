# 🀄 立直麻将训练器 (Riichi Mahjong Trainer)

一款基于 Web 的立直麻将（日式麻将）训练工具，帮助玩家练习报点计算、向听数判断和清一色听牌推断。

## ✨ 功能特性

### 🎯 报点训练器

- 随机生成手牌和场况（场风、自风、立直、宝牌等）
- 模拟真实对局场景：立直/两立直、一发、海底/河底、岭上/抢杠
- 支持吃、碰、杠（明杠/暗杠/加杠）等鸣牌展示
- 内置符数表、点数表、役种图谱和计算公式参考
- 答题模式：输入支付报点后自动校验

### 🔢 向听数训练器

- 随机生成 13 张手牌
- 支持三种牌形向听数计算：普通面子、七对子、国士无双
- 选择题答题模式，判断手牌向听数
- 展示各牌形向听数明细及最终采用值

### 🎴 清一色听牌训练器

- 随机生成已听牌的清一色手牌（13张）
- 点击候选牌选择听牌张
- 自动计算并校验听牌结果

### 🪂 待摸牌训练器

- 随机生成已一向听手牌（13张）
- 玩家需要列出手牌进入听牌的有效进张种类及数量
- 校验并提供正确结果

## 🎮 手牌输入格式

### 基本格式

- 数牌：数字 + 花色字母，如 `123m`（万子）、`456p`（筒子）、`789s`（索子）
- 字牌：数字 + `z`，如 `1z`（东）、`7z`（中）
- 花色：`m`=万、`p`=筒、`s`=索、`z`=字

### 带鸣牌格式

- 前缀：`c`=吃、`p`=碰、`k`=明杠、`a`=暗杠、`g`=加杠
- 示例：`123m c456m p111m 789s11z 4p`

### 示例

```text
123m456p789s1122z1z          # 基本手牌（最后一张为和了牌）
234m567p c123m p111z 2z2z    # 带吃碰的手牌
```

## 📐 核心算法

- **向听数计算**：支持普通面子（4面子1雀头）、七对子、国士无双三种牌形
- **得点计算**：完整符数计算 → 番数累加 → 基本点 → 最终支付点数
- **听牌检测**：基于向听数穷举，支持两面/双碰/嵌张/边张/单骑听牌判定
